# التسجيل والدخول بالبريد الإلكتروني

## الحالة داخل التطبيق

التطبيق يدعم حاليًا بصورة كاملة:

- إنشاء حساب بالاسم الكامل والبريد وكلمة المرور.
- التحقق من تطابق كلمة المرور.
- الحد الأدنى لكلمة المرور 8 أحرف.
- تسجيل الدخول بالبريد وكلمة المرور.
- رسائل أخطاء عربية واضحة.
- إرسال رابط استعادة كلمة المرور.
- استقبال جلسة استعادة كلمة المرور وتعيين كلمة مرور جديدة.
- حفظ جلسة المستخدم وتجديدها تلقائيًا.
- إنشاء ملف `profiles` تلقائيًا بعد تنفيذ migration قاعدة البيانات.
- استمرار نظام الاعتماد: إنشاء الحساب لا يمنح المستخدم حق النشر المباشر.

## إعدادات Supabase المطلوبة

داخل مشروع `rtmdaalabudycimnnena`:

1. افتح `Authentication → Providers → Email`.
2. تأكد من تفعيل مزود Email.
3. اترك `Confirm email` مفعّلًا للإنتاج حتى لا تُنشأ حسابات ببريد غير موثوق.
4. من `Authentication → URL Configuration` اضبط:
   - Site URL: `https://aymanamin.github.io/Family/`
   - Redirect URL: `https://aymanamin.github.io/Family/`
   - Local redirect: `http://localhost:5173/**`
5. من `Authentication → Email Templates` يمكن تعريب رسائل:
   - Confirm signup
   - Reset password
   - Magic link، إذا استخدمت مستقبلًا

## قاعدة البيانات

نفّذ الملف التالي من SQL Editor في مشروع Family:

`supabase/migrations/202608070001_create_profiles.sql`

هذا الملف:

- ينشئ جدول `public.profiles`.
- ينشئ ملفًا تلقائيًا لكل مستخدم جديد سواء دخل بالبريد أو Google.
- يضع الدور الافتراضي `member`.
- يمنع المستخدم من تغيير دوره أو حالة توثيقه.
- يفعّل RLS بحيث يقرأ المستخدم ملفه ويعدل الحقول الآمنة الخاصة به فقط.

## اختبار القبول

1. افتح الموقع المنشور.
2. اختر «حساب جديد».
3. أدخل اسمًا وبريدًا حقيقيًا وكلمة مرور من 8 أحرف فأكثر.
4. افتح رسالة تفعيل البريد.
5. ارجع إلى الموقع وسجّل الدخول.
6. تحقق من ظهور الاسم والبريد في رأس الصفحة.
7. نفّذ «نسيت كلمة المرور؟» وتأكد أن رابط الاستعادة يعيدك إلى الموقع.
8. ضع كلمة مرور جديدة ثم جرّب تسجيل الدخول بها.
9. تحقق من وجود سجل المستخدم داخل `public.profiles`.

## ملاحظة أمنية

لا تُخزن كلمات المرور داخل جداول التطبيق. Supabase Auth يتولى تخزينها والتحقق منها. لا يجوز إضافة أي password أو token أو service-role key إلى GitHub أو `public.profiles`.
