# المعمارية العامة

## طبقات النظام

### الواجهة

React + TypeScript + Vite، مستضافة كملفات ثابتة على GitHub Pages. الواجهة مسؤولة عن العرض والتفاعل وإدارة جلسة Supabase، وليست مصدر الصلاحيات.

### الخدمات الخلفية

Supabase يوفر:

- PostgreSQL للبيانات.
- Auth لتسجيل Google والجلسات.
- Storage للصور والوثائق.
- Row Level Security للصلاحيات.
- Edge Functions للعمليات الحساسة والمركبة.
- Realtime بصورة انتقائية للإشعارات والمراجعات.

## النموذج متعدد الأسر

- `regions`: المنطقة الجغرافية.
- `families`: الأسر والعائلات المستقلة.
- `family_branches`: فروع كل عائلة.
- `people`: سجل موحد لكل شخص.
- `person_family_affiliations`: ارتباط الشخص بأكثر من أسرة دون تكراره.
- `parent_relationships`: علاقات الأب والأم بالأبناء.
- `marriages`: الزواج ككيان تاريخي مستقل يربط شخصين وأسرتين.
- `events`: الوفيات والزيجات والسمايات والمناسبات العامة.
- `event_people` و`event_families`: أدوار الأشخاص والأسر في المناسبة.
- `submissions`: طلبات المستخدمين قبل الاعتماد.
- `profiles`: حسابات المستخدمين وصلاحياتهم المحمية.
- `person_claim_requests`: طلبات ربط الحساب بسجل شخص.
- `audit_logs`: العمليات المهمة.
- `analytics_events`: الزيارات والبحث بطريقة تراعي الخصوصية.

## المصادقة والهوية

حساب Google يثبت البريد والهوية الرقمية فقط. سجل الشخص داخل الشجرة كيان مختلف. الربط بينهما لا يتم تلقائيًا، بل من خلال طلب اعتماد.

عند أول دخول Google:

1. ينشئ Supabase مستخدمًا في `auth.users`.
2. يشغّل trigger لإنشاء `public.profiles`.
3. يكون الدور `member` دائمًا، مهما كانت قيم Google metadata.
4. يستطيع المستخدم تقديم طلبات، لكنها لا تظهر للعامة قبل الاعتماد.

## العلاقات

تخزن العلاقات الأساسية الموثقة فقط، خاصة الأبوة والأمومة والزواج. تحسب القرابات المركبة مثل العم والخال وابن العم عند الطلب أو من خلال طبقة مخصصة، مع بيان مسار العلاقة ومصدرها.

## الأمان

- RLS على كل جدول معرض للـData API.
- الزائر يقرأ الصفوف العامة والمعتمدة فقط.
- المستخدم يقرأ طلباته وملفه وما تسمح به الخصوصية.
- المشرف مقيد بالعائلات أو الفروع المسندة إليه.
- لا يستطيع أحد اعتماد طلبه الشخصي.
- الوظائف ذات `security definer` توضع في schema غير معرضة، ويُسحب تنفيذها من PUBLIC.
- المفاتيح السرية لا تدخل ملفات الواجهة أو المستودع.
