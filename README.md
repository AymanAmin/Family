# منصة أسر المنطقة

منصة مجتمعية وتوثيقية لمنطقة جغرافية واحدة تضم عدة أسر وعائلات، سواء كانت بينها صلات قرابة أو مصاهرة أو لم تكن بينها علاقة مباشرة.

تهدف المنصة إلى:

- توثيق أسر المنطقة وفروعها وأفرادها.
- إنشاء أشجار عائلية مستقلة وقابلة للترابط.
- استنتاج صلات القرابة من علاقات الأبوة والأمومة والزواج المعتمدة.
- البحث عن الأشخاص والعائلات وعرض العلاقات المتاحة.
- نشر الوفيات والعزاء والزيجات والسمايات والمواليد والنجاحات والأخبار العامة.
- مساعدة العضو الموثق على معرفة علاقته بصاحب المناسبة ومن يناسب التواصل معه للتعزية أو التهنئة.
- استقبال إضافات المستخدمين المسجلين مع منع النشر قبل اعتماد الإدارة.
- توفير لوحة تحكم شاملة للإحصائيات والزيارات والعمليات وجودة البيانات.

## قواعد أساسية

- الزائر غير المسجل يستطيع البحث والعرض فقط.
- الإضافة والتعديل يتطلبان حسابًا مسجلًا.
- التسجيل بواسطة Gmail/Google عبر Supabase Auth وسيلة دخول أساسية.
- تسجيل Google لا يربط المستخدم تلقائيًا بأي شخص داخل الشجرة؛ الربط يحتاج طلبًا واعتمادًا.
- جميع مساهمات المستخدمين تمر بدورة اعتماد إداري.
- سجل الشخص مستقل عن حساب المستخدم؛ فقد يوجد الشخص في الشجرة دون امتلاك حساب.
- يحتفظ كل شخص بسجل واحد حتى لو ارتبط بعدة أسر من جهة الأب أو الأم أو الزواج.
- الأسر تحتفظ بهويتها المستقلة، ويظهر الزواج كجسر بين أسرتين دون دمجهما.
- الخصوصية أولوية، خصوصًا للأطفال والأشخاص الأحياء.

## التقنية المستهدفة

- React + TypeScript + Vite.
- Supabase PostgreSQL + Auth + Storage + Row Level Security + Edge Functions.
- واجهة عربية RTL مع دعم الإنجليزية.
- تصميم Mobile First ومتجاوب مع جميع الشاشات.
- PWA قابلة للتثبيت.
- النشر المباشر من GitHub باستخدام GitHub Actions وGitHub Pages.

## حالة المصدر الحالية

- تطبيق React تشغيلي ومتجاوب مرتبط بمشروع Supabase ذي المعرّف `rtmdaalabudycimnnena`.
- تسجيل عادي بالبريد وكلمة المرور، واستعادة كلمة المرور وإدارة الجلسة.
- واجهة Google Auth جاهزة برمجيًا وتنتظر إعداد Google Provider داخل Supabase.
- لوحة رئيسية عائلية بأسلوب تطبيقات الأنساب العربية مع خدمات سريعة وأخبار ومعاينة للشجرة.
- دليل حقيقي للعائلات والأشخاص مع ملفات تفصيلية قابلة للفتح.
- إضافة العائلات والأشخاص والمناسبات وصلات القرابة بحالة انتظار الاعتماد.
- طلب ربط حساب المستخدم بسجل شخص ومراجعته من المدير.
- لوحة مراجعة إدارية للسجلات والعلاقات وطلبات ربط الحساب.
- ملف إعداد قاعدة البيانات الكامل: `supabase/SETUP.sql`.
- مسار الإنتاج: `https://aymanamin.github.io/Family/`.
