# معايير التصميم والاستجابة

## المبدأ

التصميم Mobile First وRTL أولًا. لا تعتبر الشاشة مكتملة إذا عملت على سطح المكتب فقط.

## أحجام الاختبار الإلزامية

- 320px
- 360px
- 390px
- 768px
- 1024px
- 1280px
- 1440px

## قواعد الواجهة

- استخدم مكونات قابلة لإعادة الاستخدام ومتغيرات تصميم موحدة.
- استخدم CSS Grid وFlexbox و`clamp()` والخصائص المنطقية مثل `padding-inline`.
- الحد الأدنى العملي لأهداف اللمس 44×44px.
- لا تضغط الجداول العريضة داخل الجوال؛ استخدم بطاقات أو صفوف قابلة للتوسعة.
- وفّر حالات loading وempty وerror وsuccess وunauthorized.
- يجب أن تعمل النوافذ والنماذج والفلاتر والشجرة ولوحة التحكم دون قص أو تمرير أفقي غير مقصود.
- احترم `prefers-reduced-motion`.
- استخدم تباينًا واضحًا وتركيز لوحة مفاتيح ظاهرًا وتسميات صحيحة للحقول.
- لا تعتمد على اللون وحده لشرح الحالة.
- للشجرة العائلية بديل نصي أو قائمة قابلة للوصول.

## الهوية الحالية

الواجهة الأولية تستخدم:

- أخضر داكن للثقة والتوثيق.
- درجات رملية للإشارة إلى المكان والذاكرة المحلية.
- بطاقات بيضاء ومساحات مريحة.
- خط عربي واضح مع عناوين بخط كوفي.

يمكن تغيير الاسم والشعار والألوان لاحقًا من نظام إعدادات دون إضعاف قواعد الاستجابة والوصول.

## مراجعة كل شاشة

قبل اعتماد أي شاشة:

1. اختبر اتجاه RTL وLTR.
2. اختبر لوحة المفاتيح.
3. اختبر العرض 320px دون تمرير أفقي.
4. اختبر النصوص الطويلة والأسماء المتشابهة.
5. اختبر البيانات الفارغة والكثيرة.
6. راجع حالة التحميل والخطأ والنجاح.
7. راجع الخصوصية قبل عرض أي معلومة عن حي أو طفل.
